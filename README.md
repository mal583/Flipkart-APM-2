# New World LIFELINE - Emergency Triage

**Flipkart APM 2029 - Case Submission (Prompt 2 - The Snap)**

## Overview
It is 2018, the day after the Thanos Snap. 50% of the global population has vanished, resulting in an immediate collapse of critical infrastructure, logistics, and supply chains. **New World LIFELINE** is a crisis protocol that overrides standard e-commerce algorithms, instantly pivoting the platform into a decentralized humanitarian triage engine.

## Core Features
*   **Crisis System Override:** Automatically cancels all pending pre-Snap orders, locks discretionary inventory (electronics, fashion), and bypasses crashed banking gateways.
*   **Essential-Only Rationing Engine:** The catalog is restricted entirely to survival goods (Hydration, Caloric Rations, First Aid). Quantities are mathematically capped based on verified household headcounts to prevent hoarding.
*   **Ghost Fleet Radar:** Geolocates abandoned delivery assets (stranded trucks) and provides surviving communities with digital master unlock codes to distribute trapped inventory locally.
*   **Zero-Friction Checkout (Deferred Ledger):** Operates on a post-currency model. Supplies are dispatched immediately for free and logged against a decentralized State Ledger for long-term government reconciliation.
*   **Dynamic SOS Drop-Zones:** Bypasses invalid pre-Snap home addresses by utilizing live GPS clusters to route surviving logistics personnel directly to refugee/survivor camps.

## How to Run
This prototype is built entirely using vanilla web technologies to ensure it runs flawlessly offline during evaluation.
1. Download or clone the repository.
2. Open the `flipkart_lifeline.html` file directly in any modern web browser (Chrome, Safari, Edge, Firefox).
3. Proceed through the simulated system boot sequence to access the triage dashboard.

## Tech Stack
*   **HTML5** (Structure)
*   **CSS3** (Styling, mobile-first responsive design)
*   **Vanilla JavaScript** (Tab navigation, cart simulation, radar UI interactions)
